# 🎬 IMDb Sentiment Analysis with LSTM

This repository contains an IMDb movie review sentiment analysis project using LSTM (Long Short-Term Memory) networks. The model is built using TensorFlow and Keras, and performance tracking is done with Weights & Biases (W&B).

## 📌 Features
- Preprocessing of IMDb movie reviews dataset
- LSTM-based sentiment classification model
- Model training and evaluation
- Performance tracking using W&B
- Visualization of training metrics

## 🚀 Quick Start
### 1️⃣ Clone the repository
```sh
git clone https://github.com/your-username/imdb-sentiment-analysis.git
cd imdb-sentiment-analysis
```

### 2️⃣ Install dependencies
```sh
pip install -r requirements.txt
```

### 3️⃣ Run the Jupyter Notebook
Open the Jupyter Notebook and execute the cells to train and evaluate the model.

Alternatively, you can run it on Google Colab:
🔗 [Google Colab Notebook](https://colab.research.google.com/drive/1mys_k-NdJyqbn5JCg6dpO0icZPJZBlRS?usp=sharing/)

### 4️⃣ Track performance on W&B
Weights & Biases is used for experiment tracking. View results here:
🔗 [W&B Project Dashboard](https://wandb.ai/bsasidharan15/imdb-sentiment-analysis?nw=nwusersasidharan1552004/)

## 📊 Results
- The model's accuracy metrics are logged in W&B.
- Visualization of loss and accuracy trends over epochs.
- CSV file with accuracy logs included in the repository.
